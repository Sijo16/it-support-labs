# Day 12 – Practical Ticket Creation and Troubleshooting

## Learning Objectives

- Create professional IT Support incident tickets.
- Classify incidents and assess priority.
- Write concise short descriptions and detailed descriptions.
- Perform safe first-line troubleshooting.
- Identify when administrator or L2 support is required.
- Document findings and escalate with relevant evidence.

**Important:** All incidents in this document are fictional scenarios created for training and portfolio practice. They are not real employment experience.

---

## 1. INC-015 – Microsoft Teams Microphone Issue

### Scenario

**User:** Priya Nair  
**Department:** HR  
**Device:** Windows 11 laptop  
**Application:** Microsoft Teams Desktop  

Priya can join Teams meetings and hear other participants, but other participants cannot hear her.

Additional information:

- The microphone works in Windows Voice Recorder.
- Other employees can use Teams normally.
- The issue started this morning.
- Priya has an important candidate interview in 30 minutes.

### Ticket Classification

**Type:** Incident

Reason: An existing application service is experiencing an unexpected interruption.

### Priority Assessment

**Suggested initial priority:** P2 – High, subject to the organisation's priority matrix.

Reason: The issue affects one user, but an important HR interview is scheduled shortly. The business impact and urgency require prompt attention.

### Short Description

User unable to transmit microphone audio during Microsoft Teams meetings.

### Detailed Description

Priya Nair from the HR department reported that other meeting participants cannot hear her during Microsoft Teams meetings. She can hear other participants, and her microphone works in Windows Voice Recorder. Other employees can use Teams normally. The issue started this morning and may affect an important candidate interview scheduled in 30 minutes.

### L1 Troubleshooting

1. Confirm the correct microphone is selected in Teams.
2. Check Windows microphone privacy permissions.
3. Check Teams device settings and perform a test call.
4. Check whether another application is using the microphone.
5. Check for pending Teams updates through the approved process.
6. Restart Teams and test again.
7. If permitted, compare functionality using Teams Web.

### Findings

- Correct microphone selected.
- Windows microphone access enabled.
- Teams test call cannot detect the microphone.
- Teams Web microphone works correctly.

### Conclusion and Escalation

The evidence suggests a possible Teams desktop application or local configuration issue.

Record the troubleshooting results and follow the approved repair or reset procedure. Escalate to L2 or an administrator if elevated permissions or reinstallation are required.

## 2. INC-016 – Shared Network Printer Not Responding

### Scenario

**User:** Daniel Thomas  
**Department:** Accounts  
**Device:** Dell Latitude laptop  
**Operating System:** Windows 11  
**Printer:** Shared HP LaserJet  

Daniel cannot print invoices using the shared office printer.

Additional information:

- The printer appears installed on his laptop.
- Print jobs remain in the queue with an Error status.
- The printer display shows that it is powered on and ready.
- Daniel can access the internet normally.
- He needs to print an urgent batch of invoices before the end of the working day.
- The impact on other employees has not yet been verified.

### Ticket Classification

**Type:** Incident

Reason: An existing printing service is unexpectedly not working for the user.

### Priority Assessment

**Suggested initial priority:** P3 – Normal, subject to verification and the organisation's priority matrix.

Reason: Only one affected user has initially been identified, and the work has a deadline later in the day. Priority should be reassessed if other users are affected or the business impact is more severe than initially reported.

### Short Description

User unable to print invoices using the shared HP LaserJet printer.

### Detailed Description

Daniel Thomas from the Accounts department reported that he cannot print invoices using the shared HP LaserJet printer. The printer appears installed on his Windows 11 laptop, but print jobs remain in the queue with an Error status.

The printer display indicates that it is powered on and ready. The user can access the internet normally. The issue started this morning and is delaying invoice processing. The user needs to complete printing before the end of the working day.

### Initial L1 Troubleshooting

1. Verify whether other employees can print successfully.
2. Check the printer's status and network connection.
3. Inspect the Windows print queue.
4. Confirm whether the issue affects all documents or a particular document.
5. Perform an approved test print.
6. Check the printer configuration and connection.
7. Check Print Spooler status using approved procedures.
8. If authorised, clear only the affected user's stuck print jobs.
9. If the issue persists, inspect the printer driver and record any errors.

### Troubleshooting Reasoning

If other employees can print successfully, the shared printer itself is less likely to be the source of the problem. Investigate Daniel's laptop, printer configuration, driver and local print queue first.

This is a working hypothesis, not a confirmed diagnosis.

### Escalation Conditions

Escalate to L2 or the printer/network administrator if:

- Approved L1 troubleshooting does not resolve the issue.
- The printer driver requires administrator-level repair.
- The printer connection or shared configuration needs privileged changes.
- The issue affects multiple users or appears to involve network infrastructure.

Include the user's details, device, printer, error status, affected-user scope, checks performed and their results.

## 5. Learning Reflection

The most important lesson from these exercises is to troubleshoot systematically rather than immediately assuming the cause.

An L1 technician should:

1. Understand the reported issue.
2. Verify the scope and business impact.
3. Classify and prioritise the ticket.
4. Perform safe and authorised checks.
5. Record findings accurately.
6. Escalate with useful evidence when required.

**Portfolio note:** These are simulated IT Support training exercises demonstrating troubleshooting knowledge and ticket documentation skills. They should not be presented as real workplace incidents or employment experience.

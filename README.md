## Troubleshooting Methodology

My general troubleshooting approach:

1. Understand the user's issue.
2. Collect relevant information.
3. Identify the scope and impact.
4. Perform authorized basic checks.
5. Identify possible causes.
6. Apply an approved solution when permitted.
7. Document findings and actions.
8. Escalate when required.

## Security Principles

- Never request or share user passwords.
- Follow least-privilege principles.
- Do not grant access without authorization.
- Avoid unnecessary administrative changes.
- Document actions accurately.
- Escalate issues beyond assigned permissions.
